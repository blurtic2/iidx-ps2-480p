# beatmania IIDX PS2 — ネイティブ480pパッチ

[English](README.md) | [한국어](README.ko.md) | **日本語**

PlayStation 2版 beatmania IIDX（9th style〜16 EMPRESS + PREMIUM BEST）を、実機で**24bitカラーのネイティブ480p**で
出力させる非公式パッチです。

オリジナルのゲームは毎フレーム640×480で描画したあと、フィールドごとに224ラインへ縮小して480iで出力しています。
このパッチはその処理をなくし、描画した画面を1:1でコピーして480pで出力するため、ゲームが実際に描いている精細さのまま表示されます。
GSMで480pを強制したときのようなライン複製は起きません。

## 2種類のバージョン

| バージョン | 表示ライン | おすすめの環境 |
|---|---|---|
| **480p**（標準） | 448ライン（オリジナルと同じ範囲） | ブラウン管、オーバースキャンのあるテレビ。ゲーム内の画面位置調整もそのまま使えます |
| **480p 480 lines** | 描画された480ラインすべて（上下16ラインずつ多く表示） | アップスケーラー、キャプチャー機器、オーバースキャンのないディスプレイ |

![左が480p（448ライン）、右が480p 480 lines](docs/images/variants-448-480.png)

*左：480p（448ライン）。右：480p 480 lines。*

480 lines版では、ゲームオプションの**縦方向**の画面位置調整は効きません（ずらす余白がないため）。横方向の調整はそのまま使えます。

## 適用方法

ご自身のディスクから吸い出したISOを使ってください。xdeltaパッチは上の表のRedump検証済みISOと**完全に同じISO**にしか適用できません。
スクリプトは、ISO内の実行ファイルが改変されていなければ適用できます。

### xdelta（いちばん簡単）

1. [Releases](../../releases)ページから、ソフトとバージョンに合った`.xdelta`ファイルをダウンロードします。
2. Delta Patcher、xdelta UIなどのxdeltaパッチャーでISOに適用します。

### Pythonスクリプト

Python 3.8以上が必要です。ISOを直接書き換えるので、コピーに対して使ってください。

```
python patch480p.py iso "beatmania IIDX 13 DistorteD.iso"
python patch480p.py iso "beatmania IIDX 13 DistorteD.iso" --480
```

- ソフトは自動で判別します。変更されるのは実行ファイル内の4バイト値数十個だけで、ISOのサイズやほかのファイルはそのままです。
- パッチ済みのISOにもう一度実行すると、2つのバージョンを切り替えます。
- 対応していない実行ファイルや、ほかのツールで改変されたものには何も書き込みません。

### PCSX2（おまけ：プレビュー・テスト用）

このパッチは実機向けです。PCSX2用の`.pnach`ファイルは、ISOを書き換えずに結果を確認したり問題を再現したりできるよう、
リリースにおまけとして添付しています（パッチ済みISOもPCSX2でそのまま動作します）。
PCSX2は実機とまったく同じ描画をするわけではないので、画質は実機で判断してください。

ファイルをPCSX2の`patches`フォルダに入れ、ゲームのプロパティで480pグループを**1つだけ**有効にしてから、ゲームを最初から起動してください。
起動時のコードを書き換えるパッチなので、ステートセーブを読み込むだけでは適用されません。
`python patch480p.py pnach <フォルダ>`で同じファイルを作成できます。

## 実機で使うとき

- **コンポーネント（D端子）ケーブル**と、480pを受けられるディスプレイ・アップスケーラー・変換器が必要です。コンポジットやS端子では480pは出力されません。
- **GSMで解像度を強制しないでください。** ゲーム自身が480pに設定します。
- 判定やタイミングには手を加えていません。変わるのは映像の出力経路だけです。

## 補足

- **13、14、15：** フルスクリーンのムービー（オープニング、エンディング）の再生中はVRAMが足りず、24bitの画面を置けません。
  そのためムービー再生中だけディザリング付きの16bitで出力し、終わると24bitに戻ります。メニューとプレー中は常に24bitです。
  オープニングムービーが再生される直前、出力が切り替わる瞬間に1フレームほど乱れた画面が見えることがあります。
- PCSX2は実機GSの動作をすべて再現しているわけではありません。そのため最終確認は実機で行いました。

## 仕組み（概要）

- 出力モードを480iから480pに変更し（`sceGsResetGraph`）、表示バッファを640×224から640×448（または640×480）の24bitバッファに変更します。
- 640×480の描画バッファから表示バッファへの毎フレームのコピーを、フィールドごとに半ラインずらして2:1に縮小する方式から、ポイントサンプリングによる1:1コピーに変更します。
- 大きくなった表示バッファを4MBのVRAMに収めるため、描画バッファを352ページに移し、（10th以降は）Zバッファを描画バッファが空けた位置に移します。
  テクスチャ領域や、これらのバッファを直接参照している演出もそれに合わせて修正します。
- 13〜15にはフルスクリーンムービー用のVRAMモードが別にあるため、ゲームのモード切り替え関数に小さなルーチンをつないで、出力形式も一緒に切り替えます。

変更する値はすべて[`patch480p.py`](patch480p.py)にコメント付きでまとめてあります。
詳しくは[docs/technical.md](docs/technical.md)（英語）を参照してください。
